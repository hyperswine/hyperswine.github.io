What I'm building

Most of my time goes into a small stack of systems built from the language up, along with a few standalone language tools written in Haskell.

  Apps and tools      QRepo, QOS programs
        │
  QOS                 Native · Portable
        │
  FP-RISC             compiler · runtime · std
        │
  Targets             x86-64 · AArch64 · RISC-V · SimpleRisc (FPGA)

  Standalone Haskell tools:  coscad (CAD) · NeoMusic (music) · Infera (logic)
  • FP-RISC is the language. Its compiler emits native code from typed IR for RISC-V, AArch64 and x64, and its profiles (Builtin, Base, ExtBase) scale from bare metal up to ordinary hosted programs.
  • QOS is the operating system written in FP-RISC. It runs natively, or portably inside a host process.
  • SimpleRisc is a RISC-V core in Clash on a Tang Nano 20K, and the FP-RISC runtime runs on it.
  • QRepo is a checkpoint tool written in FP-RISC.
  • coscad, NeoMusic and Infera are standalone languages for CAD, music and logic programming.

Lineage​

FP-RISC grew out of the Rei language prototype and is the first reference implementation of NewML, QOS is the reference implementation of the Neutron kernel, and SimpleRisc is the soft prototype of the Spectre hardware system. All of these are eventually part of Quanti, an open source vertical project.

Everything is on GitHub. See all projects, or the résumé for background.
