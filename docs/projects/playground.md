# HaskPlayground and others

## HaskPlayground

[Repository](https://github.com/hyperswine/HaskPlayground)

Scratch Haskell: small experiments that haven't grown into projects of their own. It includes a WebAssembly interpreter (a WAT parser, a VM and a capability-based actor scheduler, checked against wasmtime), a histogram-binned decision tree, a mobile-style OS shell built with Brick, and Clash exercises. NeoMusic, SimpleRisc and google-chat-mcp all started here.

## google-chat-mcp

[Repository](https://github.com/hyperswine/google-chat-mcp)

A small Haskell command-line client for Google Chat, plus a local desktop MCP plugin (TypeScript) for listing spaces, reading messages and threads, and sending messages with authorisation. OAuth credentials stay outside the repository.
