# Projects

What I'm working on right now. Most of it is written in Haskell, and several projects build on each other: FP-RISC is the language, QOS is the operating system written in it, and SimpleRisc is a RISC-V core that FP-RISC programs run on.

## Systems

- **[FP-RISC](./fprisc.md)**: a language implementation with a compiler, an interpreter (Sol), libraries and a bare-metal runtime.
- **[QOS](./qos.md)**: an operating system written in FP-RISC, available as QOS Native and QOS Portable.
- **[SimpleRisc](./simple-risc.md)**: an RV32IM(C) soft core in Clash, tested on the Tang Nano 20K.
- **[QRepo](./qrepo.md)**: a local checkpoint tool written in native FP-RISC.

## Languages and tools

- **[coscad](./coscad.md)**: a CAD language that compiles to OpenSCAD and print-ready STLs.
- **[NeoMusic](./neomusic.md)**: algebraic music notation that renders scores to audio, MIDI and sheets.
- **[Infera (NeoProlog)](./infera.md)**: a Prolog-inspired logic programming language.

## Smaller things

- **[HaskPlayground and others](./playground.md)**: scratch Haskell experiments and a Google Chat MCP plugin.
